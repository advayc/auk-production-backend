AUK VOICE ENHANCER - LISTENING RECORD

Enhancer listening test: input vs clean vs 6 pipelines

20-clip corpus (10 VCTK speakers x 2 degradations). Each card: the degraded input, the clean studio reference (target), then the six pipelines from the model-selection eval with per-clip WER badges (faster-whisper base.en vs clean-reference ASR transcript; green ≤ 0.05, amber ≤ 0.35, red above). Audio: MP3 VBR (~175 kbps) encoded with ffmpeg from the exact 48 kHz eval WAVs on the run VM. AuK outputs are raw server output - the production backend adds loudness mastering, realignment and a dry/wet blend on top. Run 2026-11-03, Colab L4.

How to ear-test: pick a card, play Input, then Clean reference, then AuK 16-step. Compare syllables, word endings and breaths against the reference, then check MossFormer2 (the only OSS baseline that cleared the do-no-harm bar) on the same clip. The spec's worst offenders to listen for: metallic/watery voice, chopped consonants, pumping between words.

Fixture swap: both replacement cases pass first try.

W4 fixture-swap addendum · 31 October 2026

The two failing custom cases from the W4 repair batch were rerun with clean replacement fixtures (no added noise, no simulated reverb), same instructions as the originals, same v035 transplant path, same automatic gate (exact transcript + speaker match ≥ 0.75).

AssessmentBoth replacement cases pass the automatic gate on the first attempt (1 seed each): exact transcript match and speaker similarity 0.82 / 0.88 against the 0.75 cutoff. The original w4-custom-01 and w4-custom-09 stay in the record on the main W4 page with fixture-defect attribution. Automatic passes are not sound-quality scores; listening review remains the owner’s call.

Why the fixtures were swapped

The two original failures traced to the fixtures, not the pipeline. Testing the raw clean versions of the same utterances (before any added noise or reverb) showed they fail the same fixture-QA check with the same mishearings (“heroin in the boat”, “of the theatre”): both are Northern Irish speakers whose pronunciation defeats the pinned ASR against the official transcript. A same-utterance replacement was unwinnable, so new clean utterances were chosen from the corpus’s fully clean subset (original recordings, no added noise, no added room simulation). Both candidates pass fixture-QA: production-equivalent ASR (faster-whisper small, beam 3) transcribes each input word-for-word against its official transcript. Neither clip collides with any existing W4 case fixture. The gate itself was never relaxed.

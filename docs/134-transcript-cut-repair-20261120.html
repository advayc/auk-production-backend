What was fixed

The model generated the requested words, but the localized fitter rejected a shorter replacement because it lacked adjacent room tone. The repaired path can use strictly checked quiet samples from that same donor. The spoken replacement is not stretched or clipped.

Neighbor-word limits now travel with the reviewed cut. The splice cannot consume the next word just to make the replacement fit. Every selected cut still needs a listening acknowledgment before generation; this test used a labeled programmatic acknowledgment.

558 CPU tests pass across all 26 test modules, run in separate groups. They include simulated cases and are not 558 real model generations. The automatic content and speaker thresholds were not lowered.
